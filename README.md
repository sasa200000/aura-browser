# Aura Browser

مرورگر اندروید با Jetpack Compose + WebView + Room.

این نسخه از سورس اصلی اصلاح شده و توسط GitHub Actions بیلد می‌شود — نیازی به
نصب Android SDK روی سیستم خودتان نیست.

## دانلود APK

1. به تب **Actions** بروید
2. آخرین اجرای موفق «Build Aura Browser APK» را باز کنید
3. از بخش **Artifacts** فایل `aura-browser-debug-apk` را دانلود کنید

## بیلد دستی

```bash
./gradlew assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## اصلاحات نسبت به نسخه اولیه

- سوییچ «ضد فیشینگ» واقعاً به لایه‌ی WebView وصل شد (قبلاً تعریف شده بود ولی هرگز صدا زده نمی‌شد)
- وضعیت گواهی TLS از اتصال واقعی خوانده می‌شود (قبلاً رشته‌ی ثابت «TLS 1.3 معتبر» روی همه سایت‌ها نمایش داده می‌شد)
- دکمه‌های back/forward کار می‌کنند — وضعیت ناوبری از WebView به مدل push می‌شود، چون Compose نمی‌تواند `canGoBack()` را reactive بخواند
- هر تب WebView مخصوص خودش را دارد؛ قبلاً همه‌ی تب‌ها یک نمونه را به اشتراک می‌گذاشتند و تاریخچه‌شان قاطی می‌شد
- حالت ناشناس از یک jar خالی شروع می‌کند و کش/فرم را هم پاک می‌کند (قبلاً کوکی را سراسری و برای همه‌ی تب‌ها خاموش می‌کرد)
- ارتقا به HTTPS روی هر ناوبری اعمال می‌شود، نه فقط بارگذاری اول
- خطای گواهی دیگر بی‌صدا رد نمی‌شود؛ بارگذاری لغو و علت گزارش می‌شود
- `WRITE_EXTERNAL_STORAGE` با `maxSdkVersion=28` اضافه شد تا دانلود روی اندروید ۷ تا ۹ کرش نکند
- لینک‌های اشتراک‌گذاری‌شده از اپ‌های دیگر باز می‌شوند (`ACTION_VIEW` / `ACTION_SEND`)
- تشخیص «آیا ورودی یک URL است» دقیق‌تر شد؛ قبلاً مقدارهایی مثل `3.5` به موتور جستجو می‌رفتند

## نکته‌ها

- APK خروجی با کلید debug امضا می‌شود (قابل نصب، مناسب تست).
- برای نسخه‌ی انتشار، مقادیر `KEYSTORE_PATH`، `STORE_PASSWORD` و `KEY_PASSWORD` را
  به‌عنوان secret تنظیم کنید؛ هیچ کلیدی داخل ریپو نگهداری نمی‌شود.
- پروژه به `.env` یا `google-services.json` نیاز ندارد؛ پلاگین Secrets به
  `.env.example` برمی‌گردد و استراتژی google-services روی `WARN` تنظیم است.
